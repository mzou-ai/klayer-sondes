# Fichier témoin de corpus

Ce fichier n'existe que pour être lu. Il est placé exactement là où le plan propose de ranger
le corpus Klayer : dans le dossier `references/` d'une skill de plugin.

Si une session parvient à lire ce fichier au chemin publié par le hook, alors l'emplacement
retenu par le plan est atteignable depuis cette surface.

Marqueur à citer :

```
SONDE-KLAYER-CORPUS-LISIBLE
```

## Contrôle de contenu

Trois lignes de contenu arbitraire, pour vérifier que la lecture rend bien le fichier entier et
pas seulement son en-tête.

- ligne-temoin-1 : chartreuse
- ligne-temoin-2 : hexadécimal
- ligne-temoin-3 : belvédère
